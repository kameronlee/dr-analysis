# Interior endpoint sensitivity to vessel-mask perturbation

Recorded 20 November 2026, before recomputing interior endpoints on perturbed graphs. This is a post hoc extension of the OCTA-500 metric audit. The original interior association and the attenuation of the raw endpoint association after dilation were already known. The paper-materials review identified robustness of the interior measure as an open question.

Use the original and three saved perturbation pipelines designated as mild in the audit. These apply 1% capillary-pixel dropout, a 10% boundary perturbation, or a one-pixel dilation. Reuse the original, fixed foveal avascular zone (FAZ) for each eye. Restrict every model to the same DR and healthy eyes with complete graphs and features under all four conditions. Report the cohort size, missing inputs and numbers by scan size and diagnosis. If any of the four sets of graphs is unavailable, stop. Verify original per-eye interior densities against the archived endpoint decomposition. Check that all endpoint categories sum to the number of endpoints in the saved features for each condition.

For each condition, count degree-one nodes in the cleaned graph lying more than five pixels from both the image edge and the FAZ, using the existing location rule. Divide by the original analysis area in square millimetres, which stays fixed because the FAZ and geometry stay fixed. Standardize within scan size on the common cohort using that condition’s sample mean and standard deviation. Estimate the DR coefficient from ordinary least squares with an indicator for 6-mm scans and the condition-specific graph length density. Use HC3 standard errors and nominal 95% Wald intervals. Compute Spearman rank correlation between original and perturbed interior endpoint density separately at 3 and 6 mm. Report all three perturbations irrespective of direction or magnitude. No new significance or selection threshold applies. The existing audit used 0.8 as its rank-agreement threshold for mild perturbations.

The comparison concerns the measured endpoint count under changes to the segmentation. It cannot establish the true anatomical endpoint count. The coefficients use condition-specific units. Differences between fitted coefficients are descriptive and their separate intervals do not test a paired difference.
